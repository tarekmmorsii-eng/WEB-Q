# تطبيق تحفيظ القرآن الكريم المتكامل (Quran Memorizer App)

تطبيق متقدم ومفتوح المصدر مبني باستخدام React و Vite لمساعدة المسلمين على حفظ القرآن الكريم، مراجعته، وتتبع إنجازاتهم. يوفر التطبيق ميزات فريدة مثل تتبع المتشابهات اللفظية، الإحصائيات الدقيقة، وعرض متقدم للصفحات ليطابق مصحف المدينة النبوية (KFGQPC).

## 🌟 المميزات الرئيسية

- **نظام المتشابهات اللفظية:** استعراض وتتبع الآيات المتشابهة لتثبيت الحفظ، وتنبيهات ذكية عند مراجعة آيات لها متشابهات.
- **عرض متقدم لصفحات المصحف:** تقديم الصفحات بجودة عالية وعرض مطابق لمصحف مجمع الملك فهد مع دعم التشكيل والرموز.
- **حاسبة الآيات (Verse Calculator):** أداة ذكية لتحديد نطاقات السور والآيات للمراجعة والحفظ بدقة متناهية وبدون أخطاء.
- **إحصائيات الحفظ (Memorization Statistics):** تتبع دقيق للتقدم وتوفير رسوم بيانية لحالة الحفظ.
- **نظام التقليب اللحظي (Swipe System):** نظام ذكي ثلاثي الشرائح يوفر تجربة تصفح لا نهائية وسلسة لجميع صفحات المصحف الـ 604، مع تحميل مسبق للخلفية لضمان سرعة فائقة وعدم وجود أي وميض أو تأخير.
- **تطبيق ويب تقدمي (PWA):** إمكانية تثبيت التطبيق على الهاتف المحمول (Android/iOS) ليعمل بكفاءة دون الحاجة لاتصال بالإنترنت.
- **واجهة قابلة للتخصيص:** إعدادات واسعة تشمل الوضع الليلي، حجم الخط، وعداد للزوار وغيرها من الإضافات المريحة للمستخدم.

## 🚀 التشغيل محلياً (Run Locally)

**المتطلبات الأساسية:**
تحتاج إلى تثبيت [Node.js](https://nodejs.org/) على جهازك.

**خطوات التثبيت والتطوير:**
1. تثبيت الحزم الاعتمادية:
   ```bash
   npm install
   ```
2. تشغيل التطبيق في بيئة التطوير محلياً:
   ```bash
   npm run dev
   ```
3. لبناء نسخة الإنتاج (Production Build):
   ```bash
   npm run build
   ```

## 📱 إدارة الشاشة (Screen Wake Lock)

- **نظام إضاءة الشاشة الذكي:** تم إضافة `useWakeLock` Hook لمنع انطفاء الشاشة أثناء استخدام التطبيق.
  - عند فتح التطبيق: تبقى الشاشة مضاءة لمدة **ساعة واحدة** كحد أقصى.
  - أثناء التشغيل الصوتي (التلاوة): تبقى الشاشة مضاءة **بشكل دائم** طالما الصوت يعمل.
  - عند إيقاف التلاوة: يعود النظام لوضع الساعة الواحدة.
  - يدعم إعادة التنشيط التلقائي عند العودة للتبويب (visibilitychange).
  - الملف: `hooks/useWakeLock.ts`

## 🔊 نظام التخزين المؤقت للصوتيات (Audio Caching System)

### المشكلة
كان نظام التخزين المؤقت للصوتيات يعتمد على **Cache API** عبر **Service Worker**، وهو يعمل بنجاح على متصفحات سطح المكتب. لكنه **يفشل على متصفحات الموبايل** لأن:
- متصفحات الهواتف ترسل **Range Requests** لتشغيل الصوت
- الـ Service Worker لا يتعامل مع Range Requests بشكل صحيح
- الروابط المباشرة تحتاج اتصال إنترنت حتى لو كان الملف مخزناً مؤقتاً

### الحل المُطبّق: IndexedDB Blob Storage
تم الانتقال من Cache API إلى **IndexedDB** مع **Object URLs**:

1. **طريقة الحفظ:** يتم جلب الملف الصوتي كـ `Blob` وحفظه في `IndexedDB` مباشرة.
2. **التشغيل المحلي:** عند طلب تشغيل الآية، يُستخرج الـ Blob ويُنشأ رابط محلي `URL.createObjectURL(blob)` ويُمرر لمشغل الصوت. هذا يجبر المتصفح على قراءة الملف **محلياً بدون إنترنت**.
3. **التوافق الكامل:** يعمل على جميع المنصات (Desktop + Mobile Web).

### الملفات المعدّلة
| الملف | الوصف |
|-------|-------|
| `services/audioCacheService.ts` | **جديد** — خدمة IndexedDB لتخزين واسترجاع Blobs |
| `hooks/useAyahAudio.ts` | معدّل — يستخدم IndexedDB + `createObjectURL` للتشغيل |
| `hooks/useWordByWordAudio.ts` | معدّل — يستخدم IndexedDB + `createObjectURL` للتشغيل |
| `components/AudioDownloadModal.tsx` | معدّل — يتحقق من IndexedDB لحالة التحميل |
| `public/sw.js` | معدّل — تم إزالة منطق Cache API للصوت (IndexedDB يتولى ذلك الآن) |

## 🎵 تحسينات مشغل الصوت (Audio Player UX) — التحديث الأخير

### التغييرات المُطبّقة

| التغيير | التفاصيل |
|---------|----------|
| **الوضع الافتراضي** | `useRangeOnly = false` دائماً عند تحميل التطبيق → تشغيل مستمر من الآية الحالية حتى نهاية القرآن |
| **زر التشغيل الرئيسي** | يفرض `useRangeOnly: false` ويبدأ تشغيل مستمر تلقائياً (يتجاهل أي نطاق محدود سابق) |
| **أزرار التخطي (⏭⏮)** | تحافظ على التشغيل المستمر بعد التخطي (`useRangeOnly: false`) |
| **زر "تطبيق" في الإعدادات** | الخيار "شغّل ما تم اختياره فقط" لا يُفعّل إلا عبر نافذة إعدادات التلاوة → تحديد النطاق → ضغط "تطبيق" |
| **التفعيل التلقائي الذكي** | عند تعديل أي قيمة في إعدادات التلاوة (السور، الآيات، التكرار) يُفعّل تلقائياً خيار "شغّل ما تم اختياره" ✅ |
| **الانتقال بين السور** | في وضع التشغيل المستمر، ينتقل تلقائياً للسورة التالية عند انتهاء السورة الحالية (`endGlobalAyah = 6236`) |

### الملفات المعدّلة
| الملف | الوصف |
|-------|-------|
| `App.tsx` | تغيير القيمة الافتراضية + تعديل `onTogglePlay` و `onNext` و `onPrevious` لفرض التشغيل المستمر |
| `components/AudioSettingsModal.tsx` | إضافة تفعيل تلقائي ذكي لـ `useRangeOnly` عند تغيير أي قيمة في النافذة |

### سلوك التشغيل الجديد
1. **التشغيل المستمر (الافتراضي):** الضغط على زر ▶ يبدأ من الآية الحالية وينتقل للآية والسورة التالية تلقائياً حتى نهاية القرآن.
2. **تشغيل النطاق المحدود:** يُفعّل فقط من خلال: فتح إعدادات التلاوة → تحديد نطاق البداية والنهاية → تفعيل "شغّل ما تم اختياره" → ضغط "تطبيق".

## 🔔 إصلاح نظام الإشعارات (Android Local Notifications Fix)

### المشكلة
كانت الإشعارات على الأندرويد تعاني من:
- **تأخير عن موعدها** بسبب عدم تجاوز وضع توفير الطاقة (Doze Mode)
- **اختفاء سريع** للإشعارات بدون بقاءها مرئية
- **انعدام الصوت** بسبب عدم إنشاء قناة إشعارات ذات أولوية عالية

### الحلول المُطبّقة

#### 1. صلاحيات AndroidManifest.xml
تم إضافة الصلاحيات اللازمة:
- `SCHEDULE_EXACT_ALARM` — جدولة إشعارات دقيقة المواعيد
- `USE_EXACT_ALARM` — للتوافق مع Android 13+ (API 33+)
- `WAKE_LOCK` — إيقاظ الجهاز عند وقت الإشعار
- `RECEIVE_BOOT_COMPLETED` — إعادة جدولة الإشعارات بعد إعادة التشغيل
- `VIBRATE` — تفعيل الاهتزاز

#### 2. قنوات الإشعارات (Notification Channels)
تم إنشاء قناتين مخصصتين:
- **`quran_critical_alarm_v1`**: للأوضاع المنبهة — أهمية قصوى (IMPORTANCE_MAX=5) مع صوت `islamic_song.mp3`
- **`quran_regular_v1`**: للتذكيرات العادية — أهمية عالية (IMPORTANCE_HIGH=4) مع صوت `paper_slide.wav`

كلتاهما تدعمان: Heads-up Notification، اهتزاز، إضاءة LED، ظهور على شاشة القفل.

#### 3. تجاوز Doze Mode
- تفعيل `allowWhileIdle: true` في كل الإشعارات المجدولة
- هذا يضمن إطلاق الإشعار في وقته الدقيق حتى لو كان الجهاز في وضع توفير الطاقة

#### 4. ملفات الصوت في Android Resources
تم إنشاء مجلد `android/app/src/main/res/raw/` ونسخ:
- `islamic_song.mp3` — صوت المنبه الإسلامي
- `paper_slide.wav` — صوت تقليب الصفحات

#### 5. إعدادات capacitor.config.ts
تم إضافة إعدادات `LocalNotifications` plugin مع القناة الافتراضية والأيقونة والصوت.

### الملفات المعدّلة
| الملف | الوصف |
|-------|-------|
| `android/app/src/main/AndroidManifest.xml` | إضافة صلاحيات الإشعارات الدقيقة |
| `android/app/src/main/res/raw/islamic_song.mp3` | **جديد** — صوت إشعار المنبه |
| `android/app/src/main/res/raw/paper_slide.wav` | **جديد** — صوت إشعار التذكير |
| `capacitor.config.ts` | إضافة إعدادات قنوات الإشعارات |
| `components/NotificationManager.tsx` | إصلاح القنوات، الصوت، Doze Mode، إلغاء الإشعارات |
