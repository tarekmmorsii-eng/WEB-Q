# تجربة «مصحف المراجعة» على iPhone

فرع التجربة هو [`codex/ios-iphone`](https://github.com/tarekmmorsii-eng/WEB-Q/tree/codex/ios-iphone). يضم مشروع Xcode يستخدم Capacitor ‏8.3.1 وSwift Package Manager. يعرض التطبيق نفس واجهة React في WKWebView ويحمّل أصول `dist` من حزمة التطبيق. الحد الأدنى في المشروع iOS 15. [وثائق Capacitor لنظام iOS](https://capacitorjs.com/docs/ios)

## البناء على Mac

استخدم Node.js ‏22 أو أحدث وXcode ‏26 أو أحدث مع تثبيت محاكي iOS. من نسخة عمل لفرع iPhone شغّل:

```bash
npm ci
npm run build
npx cap sync ios
npx cap open ios
```

اختر المخطط `App` ومحاكي iPhone في Xcode واضغط Run. أعد البناء والمزامنة بعد تعديل واجهة الويب. يمكن أيضًا فتح `ios/App/App.xcodeproj` مباشرة.

يبني مسار GitHub Actions نسخة Debug غير موقّعة ويرفق `App-simulator.zip` في المرفق `iphone-simulator-preview` قبل محاولة تشغيل المحاكي. عند نجاح التشغيل، تُرفق لقطة بدء التشغيل في `iphone-simulator-first-launch`. [عمليات بناء فرع iPhone](https://github.com/tarekmmorsii-eng/WEB-Q/actions/workflows/ios-preview.yml?query=branch%3Acodex%2Fios-iphone)

لتجربة الحزمة على Mac بمعالج Apple، فك الضغط وشغّل المحاكي، ثم نفّذ:

```bash
xcrun simctl install booted App.app
xcrun simctl launch booted com.mushafalmurajaa.app
```

## ما تغطيه التجربة

| المسار | طريقة عمله في iOS |
| --- | --- |
| المصحف والبحث | بيانات المصحف، تخطيطات الصفحات الـ604 وخطوط QPC V2 تأتي من الحزمة. البحث محلي. تنزيل تفسير لغة إضافية أو تلاوة غير مخزنة يحتاج اتصالًا. |
| التخزين | آخر صفحة وعلامات الحفظ والإعدادات في `localStorage`. ملاحظات الآيات وتلاوات القرّاء المنزّلة في IndexedDB داخل حاوية التطبيق. احفظ نسخة نصية من الملاحظات عند الحاجة. |
| المشاركة | لوحة مشاركة iOS للرابط ونص الآية أو الملاحظة، ولمشاركة MP3 وملف الملاحظات النصي عبر ملف مؤقت. يحدد التطبيق المستلم أنواع الملفات التي يقبلها. |
| التذكيرات | إشعارات محلية يسلّمها نظام iOS بعد منح الإذن، مرة واحدة أو يوميًا أو أسبوعيًا. الصوت والإظهار يتبعان إعدادات الجهاز. خدمات منبّه Android والهز والأولوية وإشعارات Push/FCM وقياس Meta خاصة بمساراتها الحالية. |
| التلاوة | يستخدم المشغّل مسار HTML Audio للتلاوة في الواجهة، من الشبكة أو من النسخة المنزّلة. استمرار التسلسل مع قفل الشاشة أو في الخلفية يحتاج تنفيذًا واختبارًا إضافيين على iPhone. |

## خطوات اختبار القبول

1. على تثبيت جديد وفي الوضع العمودي، اختر العربية وأكمل الترحيب. افتح الفاتحة والبقرة، قلّب في الاتجاهين، وانتقل لصفحة متأخرة ثم در الجهاز. راجع اتجاه الواجهة ومحاذاة النص وحواف الكاميرا ومؤشر الشاشة في عرض المصحف والقراءة المكبرة.
2. افتح البحث واكتب عبارة عربية. تحقق من بقاء الحقل والأزرار مرئية مع لوحة المفاتيح، ثم افتح نتيجة وتحقق من الصفحة والآية. احفظ علامة وملاحظة، أغلق التطبيق، وأعد فتحه للتحقق من بقائهما.
3. شغّل تلاوة عدة آيات بالتتابع، ثم جرّب الإيقاف والاستئناف. نزّل تلاوة قصيرة. أغلق التطبيق، فعّل نمط الطيران وافصل Wi-Fi، وأعد التشغيل. تحقق من فتح الصفحة، وتقليب صفحة جديدة، والبحث، وفتح علامة وملاحظة، وتشغيل التلاوة المنزّلة.
4. جرّب المشاركة مع تطبيق مثبت، وألغِ لوحة المشاركة مرة. صدّر الملاحظات إلى الملفات. امنح إذن التذكيرات عند إنشاء تذكير قريب، وجرّب وصوله أثناء الاستخدام وأثناء الخروج، ثم النقر عليه للوصول إلى موضع القراءة وتعديل تذكير آخر وإلغائه.

## التشغيل على جهاز فعلي

افتح `Signing & Capabilities` في Xcode وتحقق مع مالك حساب Apple من الفريق ومن معرّف الحزمة المسجّل لديه قبل التوقيع. المعرّف في المشروع `com.mushafalmurajaa.app` مأخوذ من إعداد المشروع الحالي. وصّل iPhone، واتبع توجيهات Xcode لتفعيل Developer Mode إذا طُلب، واختر الهاتف كوجهة تشغيل. بناء المحاكي متاح دون تسجيل معرّف أو فريق. [تشغيل التطبيقات على المحاكي أو الجهاز من Apple](https://developer.apple.com/documentation/xcode/running-your-app-on-simulated-or-physical-devices)
