# قواعد التشغيل لتطبيق Antigravity

## 1️⃣ اللغة والتواصل
- **اللغة الرسمية:** العربية (اللهجة المصرية).
- **التحديثات والتقارير:** كلها بالمصري.
- **الإنجليزية:** ممنوعة إلا بطلب صريح.

## 2️⃣ التعامل مع GitHub
- **الرفع (Push):** ممنوع تماماً إني أعمل `git push` لـ GitHub من نفسي.
- **الإذن:** لازم أستنى إذن صريح منك قبل أي عملية رفع، والأفضل إني مرفعش خالص وأسيبلك المهمة دي إنت اللي تعملها.
- **القاعدة:** إنت الوحيد المسؤول عن الرفع لـ GitHub.
