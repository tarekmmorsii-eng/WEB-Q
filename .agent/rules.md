# قواعد التعامل مع المشروع (User Preferences)

## 1. اللغة (Language)
- **يجب** أن يكون التواصل مع المستخدم باللغة العربية حصراً.
- **يجب** كتابة جميع الوثائق والخطط (implementation_plan.md, walkthrough.md, task.md) باللغة العربية.

## 2. سرعة التنفيذ (Execution Speed)
- تقليل وقت الانتظار وتجنب العمليات الطويلة غير الضرورية.
- دمج الأوامر وتنفيذ المهام بشكل مباشر وفعال.

## 3. الموافقات التلقائية (Tool Approvals)
- يفضل المستخدم الموافقة التلقائية على الأوامر.
- **يجب** استخدام `SafeToAutoRun: true` للأوامر الآمنة (مثل قراءة الملفات، سرد المجلدات، الأوامر غير التخريبية).
- تقليل طلبات الموافقة اليدوية قدر الإمكان لتسريع سير العمل.
