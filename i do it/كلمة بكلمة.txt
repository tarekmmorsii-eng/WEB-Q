إليك الملخص الشامل والمركز جداً، مكتوباً بصيغة هندسية برمجية يمكنك نسخها بالكامل وإعطاؤها لأي ذكاء اصطناعي:

# وثيقة المعمارية التقنية: مشروع المصحف المعلم (كلمة بكلمة)

## 1. نظرة عامة على المشروع

المشروع عبارة عن تطبيق ويب تفاعلي للقرآن الكريم، يعرض النص القرآني بالرسم العثماني، ويتيح للمستخدم الاستماع إلى تلاوة القرآن بطريقتين:

* **تشغيل كلمة مفردة:** عند الضغط على أي كلمة.
* **تشغيل آية كاملة (Word-by-Word Sequence):** تشغيل الكلمات تباعاً مع تظليل الكلمة المقروءة حالياً للتتبع البصري.

## 2. مصادر البيانات (Data Sources)

يعتمد المشروع بشكل أساسي على البنية التحتية المفتوحة لمشروع **Quran.com**.

* **مصدر النص والبيانات (API):**
* **الرابط:** `https://api.quran.com/api/v4/verses/by_key/{surah}:{ayah}?language=ar&words=true&word_fields=text_uthmani,location`
* **الحقول المطلوبة بدقة:** نحتاج حقل `text_uthmani` (للرسم العثماني الصحيح) وحقل `location` (الذي يحمل رقم السورة والآية والكلمة بصيغة `S:A:W`).


* **مصدر الصوتيات (Audio CDN):**
* **الرابط الأساسي:** `https://audio.qurancdn.com/`
* **القارئ المعتمد:** الشيخ محمود خليل الحصري (المصحف المعلم).
* **المجلد:** توجد الملفات في مجلد `/wbw/` (Word By Word).



## 3. المشكلة الجوهرية المكتشفة (The Core Bug)

* **وصف المشكلة:** البيانات القادمة من API الخاص بـ Quran.com تحتوي على أخطاء "إزاحة" (Data Shift) في حقل `audio_url` لبعض الآيات (مثال مثبت: سورة التوبة، آية 2). حيث يشير رابط الكلمة رقم 11 إلى الملف الصوتي للكلمة رقم 12، مما يسبب تداخلاً وخطأ في التلاوة.
* **القرار الهندسي:** **يُمنع منعاً باتاً** استخدام حقل `audio_url` القادم من الـ API (الـ JSON Response) لتشغيل الصوتيات لتجنب هذه الأخطاء المتناثرة في المصحف.

## 4. الحل المعياري المعتمد: نظام الرابط المحسوب (Calculated URL System)

لتجاوز أخطاء قاعدة البيانات، يجب على التطبيق "توليد" رابط الملف الصوتي برمجياً (Dynamically) بالاعتماد على حقل `location` المتوفر لكل كلمة.

**القاعدة الرياضية (Algorithm):**

1. قراءة حقل `location` (مثال: `"9:2:11"`).
2. تقسيم النص بناءً على النقطتين الرأسيتين `:` للحصول على (رقم السورة، رقم الآية، رقم الكلمة).
3. تحويل كل رقم إلى نص مكون من 3 خانات بإضافة أصفار على اليسار (Padding) باستخدام `padStart(3, '0')`.
* السورة 9 تصبح `009`
* الآية 2 تصبح `002`
* الكلمة 11 تصبح `011`


4. تركيب الرابط النهائي بالصيغة: `wbw/009_002_011.mp3`
5. الرابط الكامل: `https://audio.qurancdn.com/wbw/009_002_011.mp3`

## 5. محرك الصوت (Audio Engine Logic)

لمنع مشكلة تداخل الأصوات (Overlapping) والاحتفاظ بذاكرة التخزين المؤقت (Cache issues) في المتصفحات:

* لا يتم استخدام عنصر `<audio>` ثابت في الـ HTML.
* عند كل ضغطة أو انتقال لكلمة جديدة، يجب **إنشاء كائن صوتي جديد** كلياً عبر الجافاسكريبت `new Audio(url)`.
* يتم تدمير الكائن السابق (استدعاء `.pause()` وتفريغ المتغير) قبل تشغيل الكلمة الجديدة.

## 6. متطلبات واجهة المستخدم (UI/UX & Typography)

* **الخط القرآني:** يجب استخدام خط **`Scheherazade New`** حصراً لعرض النص القرآني (`text_uthmani`)، لأنه يدعم تراكب الحركات والتشكيل المعقد دون ظهور مربعات أو تداخل حروف.
* **تتبع التلاوة:** إضافة فئة (CSS Class) للكلمة النشطة لتغيير لونها وخلفيتها (Highlighting) وإزالتها عند انتهاء حدث الصوت (`onended`).
* **علامات الوقف والنهايات:** الكلمات التي تحمل نوع `char_type_name === "end"` (رموز نهاية الآيات) يجب أن تكون غير قابلة للنقر (Unclickable) ولا يتم توليد روابط صوتية لها.

## 7. الكود المرجعي لتوليد الروابط (Core Logic Blueprint)

*(يجب تضمين هذه الدالة في أي مشروع مستقبلي)*

```javascript
function generateAudioUrl(wordObj) {
    // 1. تجاهل علامات نهاية الآية والكلمات التي لا تملك موقعاً
    if (!wordObj.location || wordObj.char_type_name === "end") return null;

    // 2. تحليل الموقع (Surah:Ayah:Word)
    const parts = wordObj.location.split(':');
    if (parts.length !== 3) return null;

    // 3. إضافة الأصفار (Padding)
    const surahStr = parts[0].padStart(3, '0');
    const ayahStr = parts[1].padStart(3, '0');
    const wordStr = parts[2].padStart(3, '0');
    
    // 4. بناء الرابط القياسي
    const url = `wbw/${surahStr}_${ayahStr}_${wordStr}.mp3`;
    return `https://audio.qurancdn.com/${url}`;
}

```

**نصيحة لك عند استخدام هذا الملخص:**
قم بنسخ النص الموجود بين الخطين الفاصلين (`***`) بالكامل وألصقه للذكاء الاصطناعي الجديد وابدأ طلبك بـ: *"بناءً على وثيقة المعمارية التقنية التالية، قم ببرمجة..."* وسيفهم الآلية فوراً ويبني لك المشروع دون الوقوع في الأخطاء التي واجهناها.
